Cybersecurity Fundamentals – Task 1

1. Introduction to Cybersecurity

Cybersecurity is the practice of protecting computers, servers, networks, applications, and sensitive information from cyberattacks, unauthorized access, damage, and theft.

It helps maintain the confidentiality, integrity, and availability of digital information.

Importance of Cybersecurity

- Protects sensitive and personal information.
- Prevents unauthorized access to systems.
- Protects organizations against financial losses.
- Maintains privacy and data security.
- Helps ensure business continuity.

2. CIA Triad

The CIA Triad is a basic security model consisting of three important principles.

Principle| Description| Example
Confidentiality| Ensures that information is accessible only to authorized users.| Password protection and encryption.
Integrity| Ensures that information remains accurate and is not modified without authorization.| Hash verification.
Availability| Ensures that systems and data are accessible when required.| Backups and server redundancy.

3. Types of Cyberattacks

3.1 Phishing

Phishing is a social engineering attack in which attackers send fake emails, messages, or websites to trick users into revealing sensitive information such as passwords and banking details.

Prevention:

- Avoid clicking suspicious links.
- Verify the sender's email address.
- Use multi-factor authentication.
- Never share passwords or OTPs.

3.2 Malware

Malware is malicious software designed to damage systems, steal information, or gain unauthorized access.

Common types:

- Virus
- Worm
- Trojan
- Spyware
- Ransomware

Prevention:

- Install trusted security software.
- Avoid downloading unknown files.
- Keep operating systems updated.

3.3 Distributed Denial of Service (DDoS)

A DDoS attack attempts to make a website or online service unavailable by overwhelming it with traffic from multiple sources.

Prevention:

- Use firewalls.
- Apply traffic filtering.
- Use DDoS protection services.

3.4 SQL Injection

SQL Injection is a web application vulnerability in which an attacker inserts malicious SQL statements into application inputs to interfere with database queries.

Prevention:

- Use parameterized queries.
- Validate user input.
- Apply secure coding practices.

3.5 Brute Force Attack

A brute force attack attempts to discover passwords by repeatedly trying different combinations.

Prevention:

- Use strong passwords.
- Enable multi-factor authentication.
- Apply login attempt limits.

3.6 Ransomware

Ransomware is malware that encrypts files or locks systems and demands payment to restore access.

Prevention:

- Maintain regular backups.
- Avoid suspicious email attachments.
- Keep software updated.

4. Common Attack Vectors

An attack vector is a method or path used by an attacker to gain unauthorized access to a system or network.

4.1 Social Engineering

Social engineering involves manipulating people into sharing confidential information or performing unsafe actions.

Example: A fake technical support call asking for a password.

4.2 Wireless Attacks

Wireless attacks target weaknesses in Wi-Fi networks to intercept information or gain unauthorized access.

Example: Attacking an improperly secured Wi-Fi network.

4.3 Insider Threats

An insider threat occurs when a person with authorized access misuses that access, intentionally or accidentally.

Example: An employee sharing confidential company information without permission.

5. Basic Cybersecurity Terminology

Term| Meaning
Threat| A potential cause of harm to a system or data.
Vulnerability| A weakness that can be exploited.
Exploit| A method or code used to take advantage of a vulnerability.
Risk| The possibility and impact of a threat exploiting a vulnerability.
Firewall| A security system that monitors and controls network traffic.
Encryption| Converting readable data into an encoded form.
Authentication| Verifying the identity of a user.
Authorization| Determining what an authenticated user is allowed to access.

6. Basic Security Practices

1. Use strong and unique passwords.
2. Enable multi-factor authentication.
3. Keep operating systems and applications updated.
4. Avoid suspicious links and attachments.
5. Use secure Wi-Fi connections.
6. Back up important information regularly.
7. Follow the principle of least privilege.
8. Monitor systems for unusual activity.

7. Conclusion

Cybersecurity is important for protecting digital systems and information from different threats. Understanding the CIA Triad, common cyberattacks, attack vectors, and security practices provides a strong foundation for learning ethical hacking and information security.

These fundamentals form the basis for further practical work in cybersecurity.
