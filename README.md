Apex Planet Cybersecurity Internship – Task 1

Foundation and Environment Setup

This repository contains my work for Task 1 of the Apex Planet Cybersecurity Internship.

Objective

To understand cybersecurity fundamentals, configure a virtual cybersecurity lab, practise Linux and networking commands, and become familiar with basic cybersecurity tools.

Topics Covered

- Cybersecurity fundamentals and CIA Triad
- Common cyberattacks and attack vectors
- Kali Linux and Ubuntu Server lab setup
- Linux commands and permissions
- Networking fundamentals
- Basic cryptography and OpenSSL
- Wireshark
- Nmap
- Burp Suite
- Netcat

Lab Environment

Component| Description
Virtualization| Oracle VirtualBox
Testing Machine| Kali Linux
Target Machine| Ubuntu Server
Web Application| DVWA
Network Analysis| Wireshark
Network Scanning| Nmap
Web Testing| Burp Suite
Network Communication| Netcat

Repository Structure

- "Cybersecurity-Basics/" – Cybersecurity notes
- "Linux-Commands/" – Linux command notes and cheat sheet
- "Networking/" – Networking fundamentals
- "Cryptography/" – Cryptography notes and practical work
- "Screenshots/" – Practical screenshots
- "Task1_Lab_Setup_Report.pdf" – Lab setup report

Practical Work

The practical exercises include:

1. Linux file and directory management.
2. Linux permissions and package management.
3. Network connectivity testing.
4. ICMP packet capture using Wireshark.
5. Nmap scanning of my own Ubuntu lab machine.
6. HTTP request inspection using Burp Suite and DVWA.
7. Communication between Kali Linux and Ubuntu Server using Netcat.

Learning Outcome

This task helped me understand basic cybersecurity concepts, Linux administration, networking, and the practical use of cybersecurity tools in a controlled virtual environment.
